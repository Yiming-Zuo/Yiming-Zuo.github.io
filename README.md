# yiming-zuo.github.io

Source for Yiming Zuo's academic homepage, built with Hugo and the Hugo Researcher theme.

## Local build

Install Hugo and Dart Sass, then run:

```sh
hugo --gc --minify
```

The generated site is written to `public/` and is not committed.
